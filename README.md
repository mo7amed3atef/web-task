# TikTok Request Journey

## Website

I chose TikTok as the website for this task.

## Request Journey

When I type www.tiktok.com in the browser and press Enter, the browser acts as the client.

First, the browser uses DNS to find the IP address of the website.

After that, the request travels through the Internet to TikTok's infrastructure.

The request may pass through different components such as a CDN or load balancer before reaching an application server.

The application server processes the request and may communicate with databases or other services.

Finally, the server sends a response back to the browser, and the browser displays the website.

## Request Flow

User → Browser → DNS → Internet → Server Infrastructure → Application Server → Database/Services → Response → Browser
